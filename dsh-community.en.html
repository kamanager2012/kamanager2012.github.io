OFFICIAL FIRST

Enhance the community layer, do not rewrite the engine.

Use an official capability when it exists. Add a community extension only for a verified gap. Every claim must return to code, Runtime behavior, tests, contracts, or E2E evidence.

Official RuntimeAgent loop, model execution, tool execution, official Session persistence, and core lifecycle.
Community ProductDistribution, UX, compatibility, lifecycle wrapping, diagnostics, plugins, and safe integration.
No duplicate engineNo reimplemented Agent loop, second Session source of truth, or vendored official core packages.
Evidence firstA README is not runtime evidence; a green unit test is not Runtime E2E; fallback success is not SDK success.
